# Mobile-Sales-Insights-Dashboard
# 📊 Samsung Mobile Sales Dashboard

An interactive **Power BI Dashboard** for analyzing Samsung mobile phone sales across major Indian cities — built for data-driven decision making.

---

## 🔍 Project Overview

This dashboard provides a comprehensive view of mobile sales performance, covering **January to December** across multiple brands and payment methods. It enables stakeholders to filter, analyze, and derive insights from real-world sales data with ease.

---

## ✨ Features

- 📅 **Month-wise Filtering** — Analyze sales for any month (Jan–Dec)
- 🗺️ **City-wise Sales Map** — Interactive map showing total sales by Indian city (Delhi, Mumbai, Hyderabad, Kolkata, etc.)
- 📈 **Daily Sales Trend** — Line chart showing quantity sold per day of the month
- 💳 **Payment Method Breakdown** — Pie chart showing UPI, Credit Card, Debit Card, and Cash transactions
- ⭐ **Customer Ratings Analysis** — Bar chart showing distribution of 1–5 star ratings
- 📱 **Top Mobile Models** — Horizontal bar chart for top-selling models (iPhone SE, OnePlus Nord, Galaxy S21, etc.)
- 🏷️ **Brand Comparison Table** — Side-by-side sales, quantity, and transaction count for Apple, Samsung, OnePlus, Vivo, Xiaomi
- 🔽 **Dynamic Filters** — Filter by Mobile Model and Payment Method


2. Open `Samsung_Sales_Dashboard.pbix` in **Power BI Desktop**
3. Refresh the data source if needed
